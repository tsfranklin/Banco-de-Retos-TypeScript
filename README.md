# 🏋️ Banco de Retos Prácticos: TypeScript

Este repositorio contiene la resolución de 5 retos prácticos diseñados para consolidar los fundamentos de TypeScript. Estos ejercicios son la base preparatoria para estructurar aplicaciones escalables y dar el salto al framework Angular.

## 🎯 Conceptos aplicados en los retos

1. **Reto 1: El Contrato de la API (Interfaces)**
   - Modelado de datos estrictos usando `interface`.
   - Uso de tipado literal y propiedades opcionales (`?`).

2. **Reto 2: Inmutabilidad Tipada con Arrays**
   - Manejo de arrays de objetos (`Type[]`).
   - Modificación inmutable de estados utilizando el método `.map()`.

3. **Reto 3: La Clase Componente y la Encapsulación**
   - Programación Orientada a Objetos (POO).
   - Uso de modificadores de acceso (`public` y `private`).
   - Atajo de inicialización de propiedades en el constructor.

4. **Reto 4: Control de Errores con Tipado Restringido**
   - Creación de tipos de respuesta del servidor (Success / Error).
   - Renderizado condicional seguro basado en el estado.

5. **Reto 5: Clases Heredadas**
   - Extensión de clases usando `extends`.
   - Inicialización de clases padre mediante el método `super()`.
