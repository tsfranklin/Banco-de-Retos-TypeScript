# 🏋️ Banco de Retos Prácticos: TypeScript

Este repositorio contiene la resolución de 5 retos prácticos diseñados para consolidar los fundamentos de TypeScript. Son la base preparatoria para estructurar aplicaciones escalables en Angular.

## Características de los retos

1. **Reto 1: El Contrato de la API (Interfaces)** - Modelado de datos estrictos usando `interface` y tipado literal.
2. **Reto 2: Inmutabilidad Tipada con Arrays** - Modificación inmutable de estados utilizando `.map()`.
3. **Reto 3: La Clase Componente y la Encapsulación** - POO, modificadores de acceso (`public`/`private`) y atajo en constructores.
4. **Reto 4: Control de Errores con Tipado Restringido** - Creación de tipos de respuesta del servidor (Success / Error).
5. **Reto 5: Clases Heredadas** - Extensión de clases (`extends`) e inicialización de clases padre mediante `super()`.

## Requisitos

- Node.js
- npm
- TypeScript instalado globalmente (`npm install -g typescript`)

## Instalación y Uso

Clona el repositorio e inicia el compilador:

```bash

cd Banco-de-Retos-TypeScript
tsc --watch
